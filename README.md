# Screenshots for the filmstrip scrubber PR

Before/after captures for the slideshow filmstrip change in
cloudfra/gowebserver pull request 467, taken from the running server in
headless Chromium. The "before" images come from a binary built at the
merge base, the "after" images from the pull request head, so the pairs
are the same run of the same fixtures. Each pair also has a `-band`
crop of the bottom of the stage.

This branch only hosts images for the pull request and can be deleted
once it is merged.
